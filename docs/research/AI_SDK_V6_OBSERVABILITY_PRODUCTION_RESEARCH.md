## Executive Summary

AI SDK v6 provides comprehensive observability through OpenTelemetry integration, built-in token usage tracking, streaming observability, and production-ready error handling. The framework offers experimental telemetry features that enable deep visibility into agent behavior, cost tracking, and performance monitoring.

**Key Capabilities:**
- Native OpenTelemetry support with automatic span generation
- Token usage callbacks with detailed metrics (input/output/reasoning tokens)
- Streaming observability with SSE protocol
- Provider-agnostic error handling with retry logic
- Raw response metadata and finish reason tracking
- Prompt caching for cost optimization

### 1.2 Span Types Generated by AI SDK

#### For `generateText`:
- **`ai.generateText`** (span): Full length of generateText call
  - Contains 1+ `ai.generateText.doGenerate` spans
  - Attributes: `operation.name`, `ai.model.id`, `ai.prompt`

- **`ai.generateText.doGenerate`** (span): Provider doGenerate call
  - Can contain `ai.toolCall` spans
  - Attributes: `ai.response.finishReason`, `ai.response.msToFinish`

#### For `streamText`:
- **`ai.streamText`** (span): Full length of streamText call
  - Contains `ai.streamText.doStream` span

- **`ai.streamText.doStream`** (span): Provider doStream call
  - Contains `ai.stream.firstChunk` event
  - Contains `ai.toolCall` spans
  - Attributes: `ai.response.avgCompletionTokensPerSecond`

### 1.3 Privacy & Performance Controls

```typescript
const result = await generateText({
  model: openai('gpt-4o'),
  prompt: 'Sensitive user data here...',
  experimental_telemetry: {
    isEnabled: true,
    recordInputs: false,  // Disable for privacy
    recordOutputs: false, // Disable for privacy

      operation: 'sensitive-query'
    }
  }

```

**Use Cases for Disabling Recording:**
- Privacy concerns (PII, sensitive data)
- Reduce data transfer costs
- Improve performance (less data to serialize)
- Compliance requirements (GDPR, HIPAA)

## 3. Prompt Caching for Cost Optimization

### 3.1 OpenAI Automatic Prompt Caching

OpenAI provides automatic prompt caching for `gpt-4o` and `gpt-4o-mini` when prompts are **≥1024 tokens**.

```typescript
const { text, usage, providerMetadata } = await generateText({
  model: openai.chat('gpt-4o-mini'),

console.log('Usage with cache stats:', {
  ...usage,
  cachedPromptTokens: providerMetadata?.openai?.cachedPromptTokens

```

**Cache Behavior:**
- Prompt prefixes remain in cache for **5-10 minutes** (typical)
- Can persist up to **1 hour** during off-peak periods
- Depends on OpenAI infrastructure load
- Automatic (no configuration needed)

## 4. Streaming Observability

### 4.1 AI SDK Data Stream Protocol

AI SDK uses **Server-Sent Events (SSE)** with a structured JSON protocol.

**Protocol Features:**
- Standardized SSE format
- Keep-alive through ping
- Reconnect capabilities
- Better cache handling

**Stream Part Types:**
```typescript
type StreamPart =
  | { type: 'start', messageId: string }
  | { type: 'text-start', id: string }
  | { type: 'text-delta', id: string, delta: string }
  | { type: 'text-end', id: string }
  | { type: 'tool-call', toolName: string, input: unknown }
  | { type: 'tool-result', toolName: string, result: unknown }
  | { type: 'reasoning', textDelta: string }
  | { type: 'error', error: Error }
  | { type: 'abort' }
  | { type: 'tool-error', error: Error };
```

### 4.2 Custom Stream Format Example

```typescript
// Server: Custom stream handler
export type StreamEvent =
  | { type: 'text'; text: string }
  | { type: 'tool-call'; toolName: string; input: unknown }
  | { type: 'tool-result'; toolName: string; result: unknown };

const encoder = new TextEncoder();

function formatEvent(event: StreamEvent): Uint8Array {
  return encoder.encode('data: ' + JSON.stringify(event) + '\n\n');
}

export async function POST(request: Request) {
  const { prompt } = await request.json();

  const result = streamText({
    prompt,
    model: openai('gpt-4o'),
    tools,
    stopWhen: stepCountIs(5),
  });

  const transformStream = new TransformStream({
    transform(chunk, controller) {
      switch (chunk.type) {
        case 'text-delta':
          controller.enqueue(formatEvent({
            type: 'text',
            text: chunk.text
          }));
          break;
        case 'tool-call':
          controller.enqueue(formatEvent({
            type: 'tool-call',
            toolName: chunk.toolName,
            input: chunk.input,
          }));
          break;
        case 'tool-result':
          controller.enqueue(formatEvent({
            type: 'tool-result',
            toolName: chunk.toolName,
            result: chunk.output,
          }));
          break;
      }
    },
  });

  return new Response(result.fullStream.pipeThrough(transformStream), {
    headers: { 'Content-Type': 'text/event-stream' },
  });
}
```

## 5. Error Handling & Resilience

### 5.1 Error Types in AI SDK v6

```typescript
import {
  NoSuchToolError,
  InvalidToolInputError,
  ToolCallRepairError
} from 'ai';

try {
  const result = await generateText({
    model: openai('gpt-4o'),
    tools: { myTool },
    prompt: 'Use the tool'
  });
} catch (error) {
  if (NoSuchToolError.isInstance(error)) {
    // Model called non-existent tool
    console.error('Tool not found:', error.toolName);
  } else if (InvalidToolInputError.isInstance(error)) {
    // Model provided invalid tool inputs
    console.error('Invalid tool input:', error.toolInput);
  } else if (ToolCallRepairError.isInstance(error)) {
    // Error during tool call repair
    console.error('Repair failed:', error);
  } else {
    // Other errors
    console.error('Generation error:', error);
  }
}
```

### 5.2 Tool Execution Errors (AI SDK v5+)

Tool execution errors are **not thrown** but appear as `tool-error` content parts:


### 5.4 Full Stream Error Handling

```typescript
try {
  const { fullStream } = streamText({
    model: openai('gpt-4o'),
    prompt: 'Write a vegetarian lasagna recipe for 4 people.',
  });

    switch (part.type) {
      case 'error': {

        // Handle error without crashing
        break;
      }
      case 'abort': {
        console.log('Stream aborted');
        break;
      }
      case 'tool-error': {
        console.error('Tool error:', part.error);
        break;
      }
      case 'text-delta': {
        process.stdout.write(part.textDelta);
        break;
      }
    }
  }
} catch (error) {
  // Handle errors outside stream
  console.error('Unexpected error:', error);
}
```

### 8.2 Cost Tracking Service

```typescript
class CostTrackingService {
  private readonly pricing = {
    'gpt-4o': { input: 0.005 / 1000, output: 0.015 / 1000 },
    'gpt-4o-mini': { input: 0.00015 / 1000, output: 0.0006 / 1000 },
    'claude-sonnet-4-5': { input: 0.003 / 1000, output: 0.015 / 1000 },
  };

  calculateCost(usage: LanguageModelUsage, model: string) {
    const rates = this.pricing[model];
    if (!rates) return 0;

    const inputCost = (usage.inputTokens || 0) * rates.input;
    const outputCost = (usage.outputTokens || 0) * rates.output;

    // Account for cache savings
    const cachedTokens = usage.inputTokenDetails?.cacheReadTokens || 0;
    const cacheSavings = cachedTokens * rates.input * 0.9; // 90% discount

    return inputCost + outputCost - cacheSavings;
  }

  async trackUsage(params: {
    userId: string;
    sessionId: string;
    model: string;
    usage: LanguageModelUsage;
  }) {
    const cost = this.calculateCost(params.usage, params.model);

    await this.db.insert(usageMetrics).values({
      userId: params.userId,
      sessionId: params.sessionId,
      model: params.model,
      inputTokens: params.usage.inputTokens,
      outputTokens: params.usage.outputTokens,
      cachedTokens: params.usage.inputTokenDetails?.cacheReadTokens,
      cost,
      timestamp: new Date(),
    });

    return cost;
  }
}
```

### 8.3 Error Recovery Pattern

```typescript
class ResilientAgent {
  async execute(prompt: string, context: AgentContext) {
    let attempts = 0;
    const maxAttempts = 3;

    while (attempts < maxAttempts) {
      try {
        const result = await generateText({
          model: openai('gpt-4o'),
          prompt,
          tools: this.tools,
          stopWhen: stepCountIs(10),
          maxRetries: 2,
          abortSignal: AbortSignal.timeout(60000),
          experimental_context: context,
          experimental_telemetry: {
            isEnabled: true,
            functionId: `attempt-${attempts}`,
          },
        });

        // Success - check for tool errors
        const toolErrors = result.steps.flatMap(step =>
          step.content.filter(part => part.type === 'tool-error')
        );

        if (toolErrors.length > 0) {
          context.logger.warn('Tool errors encountered', { toolErrors });

          // Retry with modified prompt
          attempts++;
          prompt = this.modifyPromptForRetry(prompt, toolErrors);
          continue;
        }

        return result;

      } catch (error) {
        attempts++;
        context.logger.error('Generation failed', {
          error,
          attempt: attempts
        });

        if (attempts >= maxAttempts) {
          throw new Error(`Failed after ${maxAttempts} attempts: ${error.message}`);
        }

        // Exponential backoff
        await this.delay(Math.pow(2, attempts) * 1000);
      }
    }
  }

  private modifyPromptForRetry(
    prompt: string,
    errors: ToolError[]
  ): string {
    return `${prompt}\n\nPrevious attempt encountered errors: ${
      errors.map(e => e.error).join(', ')
    }. Please try a different approach.`;
  }

  private delay(ms: number): Promise<void> {
    return new Promise(resolve => setTimeout(resolve, ms));
  }
}
```

## 9. LangGraph Production Patterns (Comparison)

### 9.1 Checkpointing Architecture

LangGraph provides **built-in persistence** through checkpointers:

```typescript
import { MemorySaver } from 'langgraph/checkpoint/memory';
import { PostgresSaver } from 'langgraph/checkpoint/postgres';

// Development/Testing
const memorySaver = new MemorySaver();

// Production
const postgresSaver = new PostgresSaver({
  sync_connection: pool,  // psycopg.ConnectionPool
  autocommit: true,
  row_factory: dict_row
});

await postgresSaver.setup();  // Create tables

const graph = workflow.compile({
  checkpointer: postgresSaver
});
```

**Checkpointer Capabilities:**
- **Session Memory**: Store history of interactions, resume from checkpoints
- **Error Recovery**: Recover from failures at any step
- **Human-in-the-Loop**: Wait for approval, edit agent actions
- **Time Travel**: Edit graph state at any point in history

## 10. Framework Comparison

### 10.1 AI SDK v6 vs LangGraph Observability

| Feature | AI SDK v6 | LangGraph |
|---------|-----------|-----------|
| **Telemetry** | OpenTelemetry (experimental) | LangSmith + OpenTelemetry |
| **Checkpointing** | Manual (via context) | Built-in (MemorySaver, PostgresSaver) |
| **Token Tracking** | Built-in callbacks | Via LangSmith integration |
| **Error Recovery** | Retry + tool-error parts | Checkpoint-based replay |
| **Cost Tracking** | Manual via onFinish | LangSmith analytics |
| **Streaming** | Native SSE protocol | Streaming mode available |
| **HITL** | Manual implementation | Built-in with checkpoints |
| **Multi-step** | stopWhen conditions | Graph state machine |
| **Provider Support** | 20+ providers | LangChain providers |
| **Production Ready** | Yes (v6) | Yes (LangSmith Deployment) |

### 10.2 When to Use AI SDK v6

**Best for:**
- Provider-agnostic applications
- Next.js/React applications
- Simple to moderate agent complexity
- Real-time streaming UIs
- Cost-conscious projects (no platform fees)
- TypeScript-first development

### 10.3 When to Use LangGraph

**Best for:**
- Complex multi-agent systems
- Long-running workflows
- Built-in checkpointing requirements
- Python ecosystem preference
- Enterprise observability (LangSmith)
- State machine architectures

### 12.1 Complete Production Setup

```typescript
// production-agent.ts
import { ToolLoopAgent, stepCountIs } from 'ai';
import { openai } from '@ai-sdk/openai';
import { NodeSDK } from '@opentelemetry/sdk-node';
import { LangfuseExporter } from 'langfuse-vercel';
import { Ratelimit } from '@upstash/ratelimit';
import kv from '@vercel/kv';

// Initialize telemetry
const telemetrySdk = new NodeSDK({
  traceExporter: new LangfuseExporter({
    secretKey: process.env.LANGFUSE_SECRET_KEY,
    publicKey: process.env.LANGFUSE_PUBLIC_KEY,
  }),
  serviceName: 'production-agent',
});
telemetrySdk.start();

// Rate limiting
const ratelimit = new Ratelimit({
  redis: kv,
  limiter: Ratelimit.slidingWindow(10, '1m'),
});

// Cost tracking
class CostTracker {
  async track(params: {
    userId: string;
    model: string;
    usage: LanguageModelUsage;
  }) {
    const cost = this.calculateCost(params.usage, params.model);
    await db.insert(usageMetrics).values({
      userId: params.userId,
      model: params.model,
      cost,
      tokens: params.usage.totalTokens,
      timestamp: new Date(),
    });
    return cost;
  }

  calculateCost(usage: LanguageModelUsage, model: string) {
    const pricing = { /* ... */ };
    const rates = pricing[model];
    return (usage.inputTokens || 0) * rates.input +
           (usage.outputTokens || 0) * rates.output;
  }
}

// Production agent
export class ProductionAgent {
  private agent: ToolLoopAgent;
  private costTracker = new CostTracker();

  constructor(tools: Record<string, Tool>) {
    this.agent = new ToolLoopAgent({
      model: openai('gpt-4o'),
      instructions: 'You are a helpful production assistant.',
      tools,
      stopWhen: stepCountIs(10),
    });
  }

  async execute(params: {
    prompt: string;
    userId: string;
    sessionId: string;
    context: AgentContext;
  }) {
    // Rate limiting
    const { success } = await ratelimit.limit(params.userId);
    if (!success) {
      throw new Error('Rate limit exceeded');
    }

    const startTime = Date.now();

    try {
      const result = await this.agent.generate({
        prompt: params.prompt,
        experimental_context: params.context,
        experimental_telemetry: {
          isEnabled: true,
          functionId: `${params.userId}-${params.sessionId}`,
          metadata: {
            userId: params.userId,
            sessionId: params.sessionId,
            environment: process.env.NODE_ENV,
          },
          recordInputs: false,
          recordOutputs: false,
        },
        maxRetries: 2,
        abortSignal: AbortSignal.timeout(60000),
        onStepFinish: async (step) => {
          console.log(`Step ${step.stepNumber}:`, {
            tokens: step.usage.totalTokens,
            toolCalls: step.toolCalls?.length,
          });
        },
        onFinish: async ({ totalUsage, finishReason }) => {
          // Track costs
          await this.costTracker.track({
            userId: params.userId,
            model: 'gpt-4o',
            usage: totalUsage,
          });

          // Monitor
          const duration = Date.now() - startTime;
          console.log('Completed:', {
            finishReason,
            tokens: totalUsage.totalTokens,
            duration,
          });
        },
      });

      return result;

    } catch (error) {
      console.error('Agent execution failed:', error);
      throw error;
    }
  }
}
```
